# Sharonya Kundu: portfolio

The source of https://sharonyakundu.github.io, built with [Astro](https://astro.build).

- Text and lists: `src/data/`
- Pages: `src/pages/`
- Colours and fonts: `src/styles/global.css`

Preview on your own computer:

```bash
npm install
npm run dev
```

Every push to `main` rebuilds and publishes the site through GitHub Actions.
